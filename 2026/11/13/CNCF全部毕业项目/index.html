CNCF全部毕业项目

发表于2026-11-13|更新于2026-11-13|云原生
|字数总计:2.3k|阅读时长:7分钟

截止到目前为止（2026.11），CNCF所有毕业项目如下，共41个：

Scheduling & Orchestration（调度与编排）

Kubernetes

  • 作用：云原生容器编排的事实标准，用于自动化容器化应用的部署、扩展和管理。
  • 使用场景：大规模微服务架构、容器集群管理、应用生命周期自动化运维。

Karmada

  • 作用：多云和多集群管理系统，支持跨云、跨地域的 Kubernetes 集群协同调度。
  • 使用场景：多云架构、灾备多活、集群联邦资源统一调度与管理。

KEDA(Kubernetes Event-driven Autoscaling)

  • 作用：基于事件的 Kubernetes 弹性伸缩器，可根据外部事件（如消息队列长度、HTTP 请求数）进行精细化 Pod 扩缩容。
  • 使用场景：Serverless 负载、按需极速伸缩的微服务、消息队列消费集群。

Knative

  • 作用：基于 Kubernetes 的 Serverless（无服务器）编排框架，提供标准化的函数/应用托管与弹性能力。
  • 使用场景：构建 Serverless 平台、事件驱动型应用、冷启动按需伸缩的轻量服务。

Kubeflow

  • 作用：在 Kubernetes 上运行机器学习（ML）工作流的平台，集成数据处理、模型训练和推理部署。
  • 使用场景：AI/ML 工程师构建云原生 MLOps 流水线、大模型微调与分布式训练。

Crossplane

  • 作用：通过 Kubernetes 声明式 API 管理和编排云资源（数据库、VPC 等）的控制平面框架。
  • 使用场景：基础设施即代码（IaC）、多云基础设施统一纳管、平台工程（Platform Engineering）。

KubeEdge

  • 作用：将 Kubernetes 容器编排和管理能力扩展到边缘计算设备的开源系统。
  • 使用场景：边缘计算、物联网（IoT）节点管理、边云协同。

Application Definition & Image Build（应用定义与镜像构建）

Argo

  • 作用：基于 Kubernetes 的声明式 GitOps、工作流、渐进式交付与事件自动化工具套件。
  • 使用场景：Kubernetes 的持续交付（CD）、CI/CD 流水线编排、金丝雀发布。

Helm

  • 作用：Kubernetes 的包管理器，用于定义、安装和升级复杂的 K8s 应用。
  • 打包和分发复杂的云原生应用、多环境配置模板渲染与一键部署。

KubeVirt

  • 作用：允许在 Kubernetes 集群中同时运行和管理虚拟机（VM）与容器的技术。
  • 使用场景：传统虚机业务容器化迁移、VM 与容器混合编排统一管理。

Dapr(Distributed Application Runtime)

  • 作用：分布式应用运行时，通过标准 HTTP/gRPC API 为微服务提供状态管理、服务调用、发布订阅等能力。
  • 异构微服务开发、解耦底层基础设施实现的分布式系统。

Buildpacks(Cloud Native Buildpacks)

  • 作用：将源代码直接转为可运行 OCI 容器镜像的工具，无需手写 Dockerfile。
  • 使用场景：应用快速容器化、标准化企业 CI/CD 镜像构建流水线。

Flux

  • 作用：一组支持 GitOps 的持续交付工具，使集群状态与 Git 仓库保持同步。
  • 使用场景：Kubernetes 的 GitOps 持续交付与自动化运维。

Container Runtime(容器运行时)

Containerd

  • 作用：行业标准的产业级容器运行时，专注于简单、健壮和可移植性，管理容器生命周期。
  • 使用场景：Kubernetes 底层默认容器引擎、Docker 引擎底层核心。

CRI-O

  • 作用：专为 Kubernetes 设计的轻量级 OCI 兼容容器运行时。
  • 使用场景：纯 Kubernetes 集群中替代 Docker、对安全性与精简度要求极高的生产环境。

Cloud Native Network & Service Mesh（云原生网络与服务网格）

Cilium

  • 作用：基于 eBPF 技术的高性能容器网络、安全和可观测性插件。
  • 使用场景：大中型 Kubernetes 集群的高性能 CNI 网络、细粒度网络安全隔离与监控。

Envoy

  • 作用：高性能的边缘与服务代理，常作为网格数据平面或南北向流量入口。
  • 使用场景：API 网关、微服务南北向/东西向流量转发、Istio 底层代理。

Istio

  • 作用：业界主流的服务网格（Service Mesh），提供高级流量管理、mTLS 安全加密和分布式遥测。
  • 使用场景：微服务治理、灰度发布、流量控制、零信任安全网络。

Linkerd

  • 作用：轻量级、超快速且安全的云原生服务网格。
  • 使用场景：资源开销敏感的微服务集群、需要快速落地服务间安全加密和监控的场景。

CoreDNS

  • 作用：用 Go 语言编写的灵活、可扩展的 DNS 服务器。
  • 使用场景：Kubernetes 集群内部默认的 DNS 服务解析组件。

Security & Compliance（安全与合规）

OPA(Open Policy Agent)

  • 作用：通用的策略引擎，通过统一的语言（Rego）实施访问控制和安全策略。
  • 使用场景：Kubernetes 准入控制（Admission Control）、微服务授权、CI/CD 阶段配置合规检查。

Kyverno

  • 作用：Kubernetes 专用的策略引擎，允许使用原生 YAML 或 CEL 语法来验证、变更和生成资源。
  • 使用场景：Kubernetes 集群安全策略管控、自动注入标签、防范不安全配置。

Falco

  • 作用：云原生运行时的安全威胁检测引擎（被称为 Kubernetes 的入侵检测系统）。
  • 使用场景：实时监测容器和宿主机的异常行为、系统调用异常及安全漏洞入侵。

cert-manager

  • 作用：在 Kubernetes 中自动化管理和颁发 TLS 证书的控制器。
  • 使用场景：Ingress 自动申请与更新 Let’s Encrypt 证书、集群内微服务间 mTLS 证书自动化管理。

in-toto

  • 作用：软件供应链安全框架，用于确保软件开发全生命周期各个阶段的完整性。
  • 使用场景：高安全要求的软件供应链溯源、防篡改校验。

TUF(The Update Framework)

  • 作用：为软件更新系统提供安全框架和抗攻击保障。
  • 使用场景：安全分发软件更新、防止软件仓库遭受重放攻击和中间人篡改。

Observation(可观测性)

Prometheus

  • 作用：业界标准的云原生监控和告警工具包，基于时间序列采集指标数据。
  • 使用场景：Kubernetes 基础设施监控、微服务性能指标采集与告警。

OpenTelemetry(OTel)

  • 作用：统一的分布式追踪、指标（Metrics）和日志（Logs）采集标准与框架。
  • 使用场景：现代云原生应用的统一观测数据埋点与收集、APM 平台数据源归一。

Jarger

  • 作用：用于监视和排查复杂分布式微服务架构的分布式追踪系统（Tracing）。
  • 使用场景：微服务调用链分析、分布式系统性能瓶颈定位。

Fluentd

  • 作用：统一的日志收集与转发框架，支持结构化和非结构化日志处理。
  • 使用场景：Kubernetes 节点日志采集、日志集中化流转与对接后端存储。

Storage & Database（存储与数据库）

Rook

  • 作用：云原生存储编排工具，将分布式存储系统（如 Ceph）转化为自动化管理的 Kubernetes 服务。
  • 使用场景：在 Kubernetes 中自建生产级分布式块存储、文件存储和对象存储。

CubeFS

  • 作用：大规模分布式云原生文件/对象存储系统。
  • 使用场景：大数据分析、AI 训练海量小文件存储、容器共享存储。

TiKV

  • 作用：分布式事务型 Key-Value 数据库，具备强一致性和水平扩展能力。
  • 使用场景：分布式数据库底层存储引擎、高并发强一致性事务存储。

Vitess

  • 作用：用于 MySQL 的分布式数据库集群化中间件和水平扩展方案。
  • 使用场景：超大规模 MySQL 数据库分库分表、高可用高并发电商与互联网核心业务。

Container Registry（容器镜像仓库）

Harbor

  • 作用：企业级开源容器镜像/Helm 仓库，提供安全扫描、RBAC 权限和多云复制。
  • 使用场景：企业内部私有镜像仓库、合规镜像扫描与分发管理。

DragonFly

  • 作用：基于 P2P 技术的云原生文件分发和镜像加速系统。
  • 使用场景：大规模集群并发拉取大镜像、大文件分发加速、节省网络带宽。

Streaming & Messaging / Coordination & Discovery / Key Management（流式消息、协调与密钥管理）

NATS

  • 作用：高性能、轻量级的云原生消息系统和微服务通信层。
  • 使用场景：IoT 物联网、微服务间高并发异步消息通信、边缘计算。

CloudEvents

  • 作用：描述事件数据的通用规范，旨在简化跨服务、跨平台的事件描述与互操作。
  • 使用场景：Serverless 事件总线、多系统事件标准化接入。

etcd

  • 作用：高可用的分布式键值（Key-Value）存储系统。
  • 使用场景：Kubernetes 集群状态存储核心、分布式系统选主与配置中心。

SPIFFE

  • 作用：跨异构环境的零信任工作负载身份标准。
  • 使用场景：定义微服务间通用的安全身份标识。

SPIRE

  • 作用：SPIFFE 标准的生产级具体实现。
  • 使用场景：在多云、多集群环境中自动化颁发和验证微服务的工作负载身份。
